# Archive

This folder contains the original combined examples that shipped with the PR reviewer agent.

- `sample-pr-diff.patch` — A single patch file demonstrating multiple bugs across Appium, Playwright, and ASP.NET Core code.
- `sample-review-output.md` — The corresponding review output generated by the agent for that patch.

These files have been preserved for backward compatibility and historical reference. New examples are organized by domain in sibling folders.
